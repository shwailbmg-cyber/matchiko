# Matchiko

Organise small football games in Algeria: find players, book a pitch, stop no-shows.

- `app/` — Flutter app (Android + iOS), EN / FR / AR with full RTL
- `supabase/` — database schema, row-level security, game-loop functions, tests
- `docs/` — [architecture and the main loop](docs/ARCHITECTURE.md), [roadmap](docs/ROADMAP.md)
- `design/` — the Claude Design prototype every screen is built from

Quick start: see [`app/README.md`](app/README.md) and the commands in [`CLAUDE.md`](CLAUDE.md).
